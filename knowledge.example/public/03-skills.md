## Frontend

Täglich im Einsatz: TypeScript, React, CSS ohne Framework-Angst. Solide: Angular, Barrierefreiheit nach WCAG. Schon mal angefasst: Svelte.

## Backend

Solide: Node.js, C# mit .NET, REST-Schnittstellen, relationale Datenbanken wie PostgreSQL und SQL Server. Schon mal angefasst: Java mit Spring Boot.

## Mobile

Solide: React Native mit Offline-Synchronisation und Push-Benachrichtigungen.

## DevOps und Cloud

Solide: Docker, GitHub Actions, Azure. Grundkenntnisse: Kubernetes. Motto: «Läuft bei mir lokal» ist kein Deployment-Konzept.
